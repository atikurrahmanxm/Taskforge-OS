📅 4-Push Daily Routine

Follow this structured routine to effortlessly push 3–4 times daily:

Daily Blueprint
01. Morning 09:00 - 10:00

Plan & Goals

Set today's topics, review goals, update task checklist.

git commit -m "docs(plan): morning roadmap"
02. Mid-Day 13:00 - 14:00

Notes & Concepts

Log what you read, new tools, libraries, or architecture notes.

git commit -m "feat(notes): mid-day study log"
03. Afternoon 17:00 - 18:00

Code & Snippets

Add a problem solution, reusable helper function, or bugfix.

git commit -m "snippet(add): algorithm solution"
04. Night 21:00 - 22:30

Review & Reflection

Mark completed tasks, write brief daily reflection, sync streak.

git commit -m "chore(review): evening wrap-up"
